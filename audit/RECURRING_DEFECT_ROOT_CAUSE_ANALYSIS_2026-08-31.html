Executive Summary

The pageindex ingestion pipeline suffers from a systemic architectural pattern: single-responsibility contracts (single garble detector, single verdict writer, single state mutator) are declared in docstrings and RFCs but violated by 3–6 parallel code paths that diverge silently over successive fix waves. Four research threads converge on the same mechanism: a defect is found, a point fix is applied to one path, the parallel paths are missed, compensating heuristics are added to paper over the resulting inconsistency, and the RFC that introduced the fix is left in draft status with unresolved gates—so the next wave inherits both the original defect and the compensating workaround. This cycle has produced 8 architecture defect zones (3 critical, 4 high, 1 medium) totaling 36 bugs across garble detection, verdict computation, OCR recovery, state management, and configuration, with the three critical zones each representing a “single writer” contract violated by 5+ independent writers or paths.

Cross-Cutting Themes

6 themes across all 4 issues

Single-entry-point contracts violated by parallel bypass paths

detect_garble is documented as the sole garble API, finalize_gate_and_route as the sole state writer, and upsert_doc as the CAS-guarded verdict writer — yet each has 3–6 parallel callers that bypass the canonical path. The whole-tree fallback in _garble_check_nodes calls garble_prongs directly; recovery.py has 6 direct state.route/state.ok assignments; verdict persistence spans 5 writers with inconsistent CAS guards.

Signal destruction renders safety checks into null detectors

NFKC normalization destroys presentation-forms codepoints before garble detection sees them. Only one call site captures the flag pre-NFKC; eight others use _infer_presentation_forms which structurally returns False on post-NFKC text. Recovery compounds this by setting state.rtl_decision = None, forcing recompute on already-normalized text. The bidi coherence gate is inert (zero consumers, truthiness mismatch).

Compensating heuristics accumulate as permanent leniency

Six verdict promotion paths, an image-enrichment bypass that skips _clamp_pass, an Arabic-specific multiplier, a force_verdict_override flag, and three duplicated VLM fallback blocks were each added as temporary fixes across RFCs 022–033. None have expiry dates. The source_selection bypass grants unconditional PASS without bidi/depth caps, masking garbling for any flat doc with ≥80% enrichment ratio.

RFC lifecycle gaps leave validation gates unexecuted

RFC-037 Release B (corpus validation) was skipped while Release C (cleanup) was executed — violating the explicit sequencing gate. RFC-033 D2 Part B bidi enforcement remains gated on a re-ingest measurement never performed. RFC-040 has two unresolved open questions with no successor RFC. All four RFCs remain in draft status with no CI mechanism to surface incomplete gates.

No cross-component test oracle for the verdict/garble/recovery triad

The triad operates through implicit data-flow contracts. No test asserts the full chain from raw text → garble detection → verdict classification → recovery eligibility → recovery outcome → re-verdict. Existing tests cover each component in isolation. A threshold change in any component silently cascades without detection.

Divergent text accessors produce different content for the same block

Three independent text extraction functions — _flat_block_primary_text, _flat_search_text, and _node_text_parts — implement different strategies for the same block types. The Zone-9 header-only-table fix exists in one but not the others. This feeds different garble ratios to different detection paths and different char counts to verdict thresholds.

Architectural Recommendations

6 structural changes

Canonical block_text(block, purpose) accessor

Replace _flat_block_primary_text (flat.py:175), _flat_search_text (flat.py:200), and _node_text_parts (tree_validation.py:51) with a single function. The purpose enum (GARBLE_CHECK, SEARCH, CHAR_COUNT, DISPLAY) selects enrichment inclusions. Add a CI grep rule flagging any direct block['text'] access outside block_text().

Impact: Eliminates Zone 7 (divergent accessors) and Zone 9 (measurement blind spot). Future table-handling fixes propagate everywhere automatically.

Enforce detect_garble as sole garble entry point via __all__ and CI grep

Make garble_prongs private (_garble_prongs), not exported. Replace the direct call in _garble_check_nodes (garble.py:750) with detect_garble. CI grep blocks merges with direct garble_prongs calls outside garble.py.

Impact: Closes Zone 7 garble path divergence. Any future heuristic added to detect_garble automatically applies to all paths.

Replace severity-ordered primary_defect dispatch with all_defects-based recovery

Iterate all_defects, check recovery_eligible for each, collect all eligible recovery methods deduped by method name across all defects, and execute. Eliminates the D4 garble-priority override and any future per-pair patches. Recovery becomes correct by construction.

Impact: Closes the detection-remediation dispatch gap zone. Combined with cross-tuple dedup, eliminates duplicate recovery runs.

Heuristic registration with mandatory expiry and fire-rate metrics

Wrap each compensating path (six _try_* promotions, source_selection bypass, Arabic multiplier, force_verdict_override, each recovery state mutation) in a HeuristicEntry with: RFC origin, creation date, expiry date or graduation criteria, and a Prometheus counter. New heuristics must register to compile.

Impact: Prevents the heuristic entrenchment pattern identified across RFCs 022–033. Provides data-driven retirement decisions via fire-rate metrics.

RFC lifecycle CI gate blocking merges on skipped GATE tasks

GitHub Actions workflow parsing .agents/tasks/*.md frontmatter. Flags: later-phase items checked but earlier GATE items unchecked (the RFC-037 pattern); drafts with all tasks complete; Open Questions with no resolution. Merge-blocking for skipped gates, advisory for the rest.

Impact: Prevents the RFC-037 Release B skip pattern. Makes RFC completion a first-class CI concern.

Property-based triad integration tests via hypothesis

Generate document structures with varying garble ratios, table content, node counts, and depths. Assert cross-component invariants: garble detected ⇒ hard-fail or marginal; garble defect ⇒ never PASS via promotion; _keep_best_wins never reverts objectively better retries; no-op recovery cycle preserves PASS. CI with max_examples=200, nightly with 10,000.

Impact: Catches threshold-coupling regressions across all three triad components. Properties survive refactors.

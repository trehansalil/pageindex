B1The override passed a bare state.gate_result as vt_raw

ExtractionState.gate_result starts as None (helpers/types.py:219), and the legacy branch resets it to None (:459).

A None vt_raw takes the legacy path in finalize_gate_and_route (:411) and raises TypeError.

The existing override sites use a fallback (recovery.py:947, :1125-1126, :1206, :1290).

The call is now finalize_gate_and_route(state, state.gate_result if state.gate_result is not None else (state.ok, state.reason), settings.flat_doc_routing, force_route=Route.REJECT).

The note that state.reason = str(vt_raw) is harmless, because the REJECT arm reads first_defect.value (indexer.py:2683-2684), is in design AD2 and §9, Task 7.3 and the RFC's Option C. A new test covers the gate_result is None case.

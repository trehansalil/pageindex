RFC-050 & RFC-051 — Iteration 4 Review Report

Date: 2026-09-24  |  Iteration: 4 of rfc-iterate  |  Reviewer agents: rejected-doc-coverage, from-raw-feasibility

Summary: Two focused agents found 2 significant issues: (1) rejected documents bypass persist methods entirely, leaving AC2 unsatisfied — fixed by adding save_raw on the reject path with sha256[:8] as key; (2) the from-raw path (D4) has two separate threading paths (not one) and non-trivial state reconstruction — effort revised 8-10h → 12-16h, new task 5.2a added. 9 patches applied across 3 files. RFC-051 unchanged this iteration.

Review Agents & Findings

Agent 1: rejected-doc-coverage

Verified whether rejected documents get raw output under the Iteration 3 design (save_raw in persist methods only).

#FindingTypeResolution
F1 GAP: Rejected docs bypass persist methods entirely. The index() method's match (state.ok, state.route) dispatch shows:
  • (False, Route.REJECT) → save_quarantine() → raises LowQualityTreeError — never reaches persist methods
  • flat_garble_unrecovered → raises LowQualityTreeError — never reaches persist methods
AC2 explicitly says "even if quality gating fails (REJECT route)" but the Iteration 3 design only covers persist-method paths.		 Design gap FIXED — Added save_raw on reject path using sha256[:8] as doc_id key (since real doc_id never generated for rejects). Updated AC2, D3, Property 2, Task 3.1 with 2 additional call sites.

Agent 2: from-raw-feasibility

Traced the --from-raw flag through all pipeline layers to verify feasibility and effort estimate.

#FindingTypeResolution
F2 Two separate paths, not one. preprocess_client.py uses plain sys.argv and calls _run_converter_subprocess directly — bypasses HTTP/arq entirely (2-layer path). The HTTP/arq path is a separate 4-layer path. RFC described one 4-layer path. Scope underestimate FIXED — D4, Task 5.1, Task 5.2 revised to acknowledge two separate paths. Task 5.1 scoped to CLI path only; Task 5.2 scoped to HTTP/arq path.
F3 State reconstruction complexity. _convert_to_tree sets ~10+ state fields beyond md_content: state.content_class, state.converter_name, state.arabic_ratio, state.garbled_text_layer, state.classification, etc. From-raw can't just set md_content and skip everything — downstream logic depends on these fields. Scope underestimate FIXED — New Task 5.2a (state reconstruction) added. D4 effort revised 8-10h → 12-16h. Design Property 4 updated with two-path + state reconstruction note.
F4 process_document_job impedance mismatch: assumes input is original document (downloads from staging). For --from-raw, input source is stored raw markdown in MinIO — fundamentally different fetch logic. Impedance mismatch NOTED in Task 5.2 description.

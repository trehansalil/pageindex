## CAUSAL CHAIN SUMMARY (Fixes disabling/fighting other fixes):

### CHAIN 1: Low_content_density Gate Systemic Failure (Run 13)
Mechanism: Tree-builder oversegmentation or gate threshold change
Affected Docs: Penal Code, federal_decree_law_no_33 (English), مرسوم 33 (Arabic)
Evidence:
  - Run 12 PASS (chars_per_node ~361-442, borderline but passing)
  - Run 13 ERROR (chars_per_node 408-459, below 500 threshold)
  - Run 14 PASS (gate no longer trips — gate logic reverted)
What it broke: 3 previously-passing large legal documents rejected
What was fixed: Low_content_density gate was too strict or node-counting changed
Gate mechanism reversal needed: Either tree-builder de-fragmentation or gate threshold raised

### CHAIN 2: Arabic/Mixed-Language Block-Handling Regression (Run 13)
Mechanism: Single upstream code path change to Arabic block processing
Affected Docs: MOU (89% loss), SLA (total loss), قرار 106 (92% loss, truncation)
Also: Garble-gate misfires on affected docs (ratio=1.00 false positive)
Evidence:
  - Run 12: All three docs extract successfully (166 nodes / 13.5k, 264 nodes / 27.9k, 179 nodes / 26k)
  - Run 13: Catastrophic failures (20 nodes / 1.5k, 0 nodes / 0 chars, 11 nodes / 2k)
  - Run 14: Partial recovery (SLA 219 nodes / 27.8k, قرار 106 160 blocks / 26.1k, MOU 134 blocks / 13.5k)
What it broke: Arabic/mixed-language extraction + gate's Arabic-text detection
Root cause suspicion: "RFC-029/030 Arabic-handling changes" (cited in Run 13 audit)
What was fixed: Some recovery by Run 14; Run 15 shows further improvements but with identity issues

### CHAIN 3: RTL/Bidi Reversal Blind Spot + Corruption Spread (Run 13-14)
Mechanism: Gate cannot detect RTL reversal; RFC-029/030 changes may introduce or spread corruption
Affected Docs: سياسة حوكمة (persistent), ﺣﻘﻮق اﻹﻧﺴﺎن (persistent)
Evidence:
  - Run 11: سياسة حوكمة 100% RTL title reversal (FAIL), ﺣﻘﻮق detected 93.6% presentation-forms garble (FAIL)
  - Run 12: سياسة حوكمة judge flip to PASS (bug still present); ﺣﻘﻮق ERROR (artifact lost)
  - Run 13: سياسة حوكمة MARGINAL (RTL titles re-detected); ﺣﻘﻮق recovered PASS
  - Run 14: سياسة حوكمة FAIL (corruption spreads from titles to 87.5% of node bodies); ﺣﻘﻮق MARGINAL (42% garble detected)
  - Run 15: Both still FAIL/PASS with same defect (live tree contradicts PASS claim for ﺣﻘﻮق)
What it broke: Gate blind spot allows RTL/bidi defects to persist; RFC-029/030 changes amplify corruption
Gate defect: Stores title field not inspected by garble-gate quality checks
What needs fixing: Gate must inspect node titles + detect RTL reversal; RFC-029/030 changes need review for bidi handling

### CHAIN 4: Picture/Image Enrichment Regression (Run 13)
Mechanism: Enrichment step over-strips content on short flat documents
Affected Docs: Reitlehrer (32% char loss)
Evidence:
  - Run 12 PASS: 4,082 chars
  - Run 13 MARGINAL: 2,768 chars (32% loss)
  - Run 14 MARGINAL: same 2,768 (RFC-029 D3 fence/HR stripping regression)
  - Run 15 PASS: same 2,768 (judge reclassifies image as non-substantive)
What it broke: Text derived from/alongside images lost on short flat documents
RFC attribution: "RFC-029 D3 fence/HR stripping" cited explicitly
What was fixed: Picture enrichment step regression introduced by fence/HR stripping logic

### CHAIN 5: Garble Gate False Positive on Clean Mixed-Script Arabic (Run 14-15)
Mechanism: Gate gives ratio=1.00 on clean Arabic text; Run 14 judge overrides to 0.067; Run 15 gate fires again
Affected Docs: SLA (اتفاقية مستوى الخدمة)
Evidence:
  - Run 14 PASS: Stored verdict_reason `garbling(ratio=1.00)` (false positive); judge overrides to recomputed 0.067
  - Run 15 MARGINAL: Stored verdict_reason `garbling(ratio=1.00)` reappeared; judge doesn't override
What it broke: Clean bilingual Arabic/English documents wrongly penalized
Gate defect: Full-text tautology or missing separator in `_garble_ratio` calculation (cited in Run 15 reconciliation as finding A33-C4a)
Non-determinism: Gate produces ratio=1.00 inconsistently (might depend on artifact order or scoring timing)

### CHAIN 6: Persistence Timing Race (Run 15)
Mechanism: Scorer reads MinIO before worker write completes
Affected Docs: القرار التنظيمي
Evidence:
  - Run 15 scoring: NoSuchKey, ERROR verdict
  - Run 15 publish-time verification: Artifacts exist (83 nodes / 48k chars, processed 2026-08-06T11:05:56Z)
What it broke: Incremental ingest+score pipeline has race between worker write and scorer read
RFC attribution: None; ordering bug in pipeline orchestration
What needs fixing: Read-after-write guarantee needed (polling, event-driven, or linearized timestamps)
